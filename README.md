# СПИД — учёт пробега и топлива автопарка

Веб-приложение (PWA) для учёта пробега и расхода топлива Газелей и других машин парка.
Водители вносят показания одометра с телефона, руководитель видит расход, перерасход и отчёты по месяцам.

## Что умеет

**Водитель** (телефон, Android или iPhone):
- начало и конец смены — пробег + обязательное фото одометра;
- заправка — вид топлива (бензин / газ / дизель), литры, сумма в ₸, «до полного бака», фото чека по желанию;
- работает без интернета: записи и фото хранятся в телефоне и отправляются сами, когда появится связь;
- проверяет ввод: предупреждает, если пробег меньше прошлого или слишком большой скачок.

**Руководитель** (телефон или компьютер):
- **Отчёт за месяц**: пробег, литры по видам топлива, затраты в ₸, фактический расход, норма, отклонение и перерасход в ₸ — по каждой машине и по каждому водителю;
- **Сравнение одинаковых машин** (например, все Next 6 м на бензине) — сразу видно, какая машина жжёт больше остальных;
- **Замечания**: перерасход, пробег вне смены, уменьшение одометра, скачки пробега, незакрытые смены, подозрительно низкий расход (пропущенная заправка);
- **Журнал** всех записей с фото, исправление и удаление ошибочных записей;
- **Машины** и **Водители**: добавление, закрепление водителя за машиной, подтверждение регистрации, сброс пароля;
- **Выгрузка в Excel**: листы «Машины», «Водители», «Заправки», «Смены», «Замечания».

## Как считается расход

Метод «от полного бака до полного»: между двумя заправками до полного бака машина сожгла столько,
сколько залили во второй раз (плюс неполные дозаправки между ними). Расход = литры ÷ км × 100.
Газ и бензин у машин с ГБО считаются раздельно.

**Норма** не задаётся вручную. Для каждой машины и каждого вида топлива это медиана расхода по её
последним 3–6 интервалам за 4 месяца. Поэтому норма сама подстраивается под сезон (зимой расход выше).
Перерасход — когда расход выше нормы больше чем на 10%; в «Замечания» попадает превышение от 25%.

Литры распределяются по водителям пропорционально километрам, которые каждый проехал по своим сменам.

## Устройство

- Фронтенд: React + TypeScript + Vite, PWA (устанавливается на телефон как приложение). Хостинг — Cloudflare Pages.
- Бэкенд: Supabase — база Postgres, вход по телефону и паролю, приватное хранилище фото, права доступа (RLS).
- Схема базы и начальный список машин: [`supabase/migrations/001_init.sql`](supabase/migrations/001_init.sql).
- Логика расчёта: [`src/lib/calc.ts`](src/lib/calc.ts), тесты — [`src/lib/calc.test.ts`](src/lib/calc.test.ts).

## Развёртывание

1. **Supabase**: создать проект (бесплатный тариф), выполнить `supabase/migrations/001_init.sql` в SQL Editor.
2. В Supabase: **Authentication → Sign In / Providers → Email** — выключить **Confirm email**
   (водители входят по номеру телефона, почта не используется).
3. Скопировать `.env.example` в `.env` и вписать `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`
   (Project Settings → API).
4. Собрать: `npm install && npm run build`. Папку `dist` опубликовать на Cloudflare Pages
   (или подключить репозиторий в Cloudflare Pages: команда сборки `npm run build`, папка `dist`,
   переменные `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`).
5. **Первым** зарегистрироваться руководителю — первый пользователь автоматически получает права руководителя.
   Остальные регистрируются как водители и ждут подтверждения во вкладке «Водители».
